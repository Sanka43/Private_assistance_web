QUICK START GUIDE
--------------------------------------------------------------------------------

1. RUNNING RUXT DESKTOP (GUI & TRAY COMPANION):
   - Double-click 'RuXt-Desktop.exe' to launch.
   - A system tray icon with the RuXt emblem will appear in your Windows taskbar.
   - Click the tray icon to open the desktop companion window.
   - By default, it automatically connects to:
     http://localhost/PrivateAssistance
   - If your server is on a different port or LAN address, launch with:
     RuXt-Desktop.exe --url http://your-ip-or-domain/PrivateAssistance

2. RUNNING RUXT AGENT (HEADLESS / CLI):
   - For background or headless operation, run in Command Prompt or PowerShell:
     .\ruxt-agent.exe --url http://localhost/PrivateAssistance
   - Use '--token <your_token>' to link your specific device token.

3. SECURITY & PRIVACY:
   - 100% Private: Stored and executed entirely on your hardware.
   - No telemetry, no third-party tracking, no cloud dependencies.
   - Built natively with Microsoft .NET Win32 runtime (< 50 KB, instant 0.1s launch).

SYSTEM REQUIREMENTS:
- Windows 10 or Windows 11 (64-bit)
- Microsoft .NET Framework 4.5+ or 4.8 (pre-installed on Windows)
- Local or networked PrivateAssistance server instance
